# FeelFed Design System — Reference Assets

| File | Subject | Kind | Notes |
|------|---------|------|-------|
| `logos/feelfed-cream-logo.png` | FeelFed bowl mark | `brand-asset` | Cream background; used as interactive hero center in the hero app. Primary brand mark. |
| `logos/feelfed-teal-icon.png` | FeelFed app icon | `brand-asset` | Teal rounded-square; used as browser favicon and app icon. |

## Logo anatomy

- **Bowl** — teal (#3A8F88), the container of nourishment
- **Leaf sprigs** — teal (#3A8F88), growth and food awareness
- **Peach dot** — peach (#F0A576), gentle accent of energy and warmth

## Usage notes

- Use `feelfed-cream-logo.png` for placement on light/cream backgrounds and as the center-piece of the interactive ring component.
- Use `feelfed-teal-icon.png` as the `<link rel="icon">` favicon and for any app-icon contexts.
- Never invent or approximate the logo — always pull from this directory.
- Both assets are 1024×1024 PNG; resize as needed, preserve aspect ratio.
